# 🏕️ Camping Data Dashboard

## 📖 Description

**Camping Data Dashboard** is an interactive web application built with **React** and **Node.js**, designed to analyze, compare, and visualize data related to campgrounds.  
The main goal of the project is to provide a clear and intuitive overview of the performance and characteristics of different accommodations.

---

## 🚀 Main Features

### 🔹 1. Camping Comparator  
The **Camping Comparator** module allows users to:
- Compare multiple campgrounds based on various criteria such as:  
  - Competitors  
  - Distance  
  - Accommodation size  
  - Range and category  
- Visualize accommodation **prices** using a **Line Chart**  
- Explore the **geographical location** of campgrounds through a **dynamic map**

### 🔹 2. Performance Analysis  
- Identify the **Best Seller**  
- Display the **Maximum** and **Minimum Prices**  
- Determine **High** and **Low Seasons**  
- Detect the **Largest** and **Smallest Accommodations** within a campground
